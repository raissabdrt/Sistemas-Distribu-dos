# Atividade 1 - Cliente/Servidor com sockets

Ambos os servidores usam a porta 8000 e criam uma thread por cliente.
Rode um servidor por vez.

## a) Horário
```bash
python servidor_horario.py     # terminal 1
python cliente_horario.py      # terminal 2
```

## b) String reversa
```bash
python servidor_reverso.py     # terminal 1
python cliente_reverso.py      # terminal 2
```
